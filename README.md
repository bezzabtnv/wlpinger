# WL pinger
WL PINGER проверка доступности сайтов в том числе белых списков. Загрузите список сайтов которые нужно проверить на доступность и программа их проверит. Программа разработана на Delphi RAD Studio 12.3. Windows и Android версия. 
Андроид версия на [Google play](https://play.google.com/store/apps/details?id=com.embarcadero.wl_pinger).

## 📋 Требования
Androiod 6+, 
Windows 64/32 bit.

Запрещается использовать код в любых коммерческих проектах.
